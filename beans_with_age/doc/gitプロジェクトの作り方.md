以下のgitプロジェクトの作り方に間違いがありますか？

githubにリポジトリを作る。仮に "kazuate_beans" とする。

そのリポジトリをローカルPCにクローンする。
ここでは、~/git/kazuate_beans とする。

Eclipseを起動し、ワークスペースを選択する。

ファイル --> インポート --> Git --> Gitからプロジェクト
--> 既存ローカル・リポジトリー 

とすると、"Gitリポジトリーの選択" が開くので、
下のリストになけれが、"追加" をクリックし、
クローンしておいたリポジトリを選択する。

"新規プロジェクト・ウィザードを使用してインポート" を選択。

"ウィザードを選択" ダイアログが開くので、"動的Webプロジェクト" を
選択する。

ここで、プロジェクト名を指定すると、

「すでにプロジェクトが存在します」というエラーが出る。

どこか手順に間違いがあるでしょうか？
