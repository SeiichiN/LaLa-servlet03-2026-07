servletで、
```
HttpSession session = request.getSession(false);
```
とした場合、アプリの起動直後なら、
セッションスコープは作成されないという理解でいいですか？
もちろん、ブラウザもいったん閉じてから動作させたとしてです。

この状態で、
```
if (session == null) {
  System.out.println("セッションはありません");
}
```
としても、これは表示されません。
デバッガーで確認すると、sessionインスタンスはできているようなのです。
このあたりの事情を教えてください。

----

はい、その理解はほぼ正しいです。

`request.getSession(false)` は、

* すでにセッションが存在していれば、その `HttpSession` オブジェクトを返す。
* セッションが存在しなければ、**新しく作成せずに `null` を返す。**

というメソッドです。

したがって、アプリ起動直後で、

* ブラウザを完全に閉じる
* Cookie（`JSESSIONID`）が残っていない
* どこでも `getSession()` や `getSession(true)` を呼んでいない

という条件なら、

```java
HttpSession session = request.getSession(false);

if (session == null) {
    System.out.println("セッションはありません");
}
```

は表示されるはずです。

---

しかし、

> デバッガーで確認すると、sessionインスタンスはできている

とのことなので、どこかでセッションが作られている可能性が高いです。

よくある原因を挙げます。

### 原因1: JSPが勝手にセッションを作っている

実は、JSPではデフォルトで

```jsp
<%@ page session="true" %>
```

になっています。

つまり、JSPを1回表示しただけで、

```java
request.getSession(true)
```

が内部で実行され、セッションが作成されます。

たとえば、

```java
protected void doGet(...) {
    HttpSession session = request.getSession(false);

    RequestDispatcher rd =
        request.getRequestDispatcher("/index.jsp");

    rd.forward(request, response);
}
```

としている場合、

1. `getSession(false)` の時点では `null`
2. `index.jsp` が表示される
3. JSPが自動的にセッションを作成する

ということが起こります。

---

### 原因2: どこかで `request.getSession()` を呼んでいる

次のコードは、

```java
HttpSession session = request.getSession();
```

と同じ意味です。

```java
HttpSession session = request.getSession(true);
```

プロジェクト内の別のサーブレットやフィルタで、このコードが実行されているかもしれません。

---

### 原因3: デバッガーがメソッドを評価している

Eclipse のデバッガーは、変数の内容を表示するために内部でメソッドを呼び出すことがあります。

特に、

```java
request
```

や

```java
session
```

の中身を展開して見ていると、サーバー側の実装によっては状態が変わることがあります。

そのため、まずはデバッガーではなく、

```java
HttpSession session = request.getSession(false);

System.out.println(session);
System.out.println(request.getRequestedSessionId());

if (session == null) {
    System.out.println("セッションなし");
}
```

を出力して確認してみることをおすすめします。

---

確認のために、次のコードをサーブレットの先頭に置いてみてください。

```java
HttpSession session = request.getSession(false);

System.out.println("session = " + session);

Cookie[] cookies = request.getCookies();

if (cookies != null) {
    for (Cookie c : cookies) {
        System.out.println(
            c.getName() + " = " + c.getValue()
        );
    }
}
```

ここに

```text
JSESSIONID=...
```

が表示されるなら、すでにセッションが作られています。

もし「絶対にセッションを作っていないはずなのに `session` が `null` ではない」という場合は、サーブレットや JSP のコードを少し見せていただければ、原因を絞り込めると思います。
